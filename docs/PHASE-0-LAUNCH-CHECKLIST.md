## CAN LEARN DURING PILOT
- acceptance rate;
- true labour minutes;
- battery replacement economics;
- returns and repeat faults;
- sell-through by channel;
- scrap rebate;
- supplier quality;
- storage burden;
- profitable category mix.

## LATER / SCALE-UP
- paid ITAD tooling;
- formal certifications;
- Snipe-IT/ERP;
- warehouse;
- public drop-off;
- staff;
- board-level repair;
- large battery handling;
- formal marketplace programs such as Back Market/Reebelo.
