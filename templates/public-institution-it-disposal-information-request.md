# Public institution IT disposal information request

Adapt for **TAFE NSW, Western NSW Local Health District/eHealth NSW, or Charles Sturt University**.

Start informally where the agency permits it. Escalate to GIPA only if necessary.

## Record description

**Period:** 1 July 2023 to present.

I seek existing records relating to the retirement/disposal of laptops, desktop computers and associated data-bearing IT equipment used by [AGENCY / DUBBO CAMPUS OR DISTRICT].

Please provide, where held:

1. current provider(s) used for collection, ITAD, data sanitisation/destruction or e-waste processing;
2. relevant contract/purchase-order/panel reference and current term;
3. whether the provider collecting from Dubbo is a direct contractor or subcontractor;
4. aggregate number or weight of laptops/desktops retired in each financial year;
5. average/typical refresh cycle if recorded in asset plans;
6. blank/redacted sample sanitisation or destruction certificate;
7. recorded outcome categories for retired equipment: internal redeployment, lease/vendor return, sale, donation, reuse/refurbishment, parts, recycling or destruction;
8. aggregate counts/percentages by those outcome categories if existing reports contain them;
9. documents describing whether regional/local subcontractors may participate; and
10. any records showing residual-value return/rebate or disposal cost at an aggregate level.

I do not seek personal information, user data, device serial numbers, security credentials or commercially sensitive line-item pricing where redaction/aggregation can allow release.
