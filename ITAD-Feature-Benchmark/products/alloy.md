# Alloy Navigator

Checked: 2026-10-02 · Evidence: EVD-BENCH-023 · Role: ITSM / ITAM

## Publicly advertised features

IT lifecycle tracking from acquisition to retirement; discovery, financial/purchasing records, contracts and equipment checkout. Official mobile documentation describes barcode/QR lookup and deploy/repair/retire actions; finance help includes a retirement date.

## Limits and unresolved details

Generic lifecycle support does not establish a native erasure connector. Confirm API rights, edition and customer-specific workflow mapping.

## AssetFlow implications

Use this product as a benchmark in these domains: LIFE,INV,INT. Build operational records and release controls in AssetFlow; use documented adapters for external device processing. Do not label a browser workflow as equivalent to its erasure engine, certification or physical automation.

## Demo questions

- Which current edition, versions and device models support the advertised workflow?
- Can we obtain a sample report, API schema and failed-operation example?
- Which capabilities require add-ons, hardware, paid lookups or managed services?
- How are identity conflicts, retries, operator overrides and evidence integrity handled?
