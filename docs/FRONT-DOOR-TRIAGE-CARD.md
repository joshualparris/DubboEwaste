# Front-Door Triage Card

**Rule:** accept only when **ownership + safety + lock/data status + viable route + storage** are sufficiently known.

## 1. Ownership
- Who owns it?
- Is the person/business authorised to transfer it?
- Record source + signature/authority.
- Record serial/IMEI where present.
**STOP:** unclear ownership, altered/missing identifiers that raise concern, or conflicting story.

## 2. Safety
- swollen/leaking/hot/smoking battery?
- fire/flood/severe crush/puncture?
- pest/biological contamination?
- damaged mains wiring/plug/internal PSU?
**STOP/REJECT:** immediate lithium or electrical hazard. Do not charge.

## 3. Locks
- Apple Activation Lock / ABM MDM?
- Android FRP / Knox Guard / carrier block?
- Windows Autopilot / organisation enrolment?
- Chromebook enterprise enrolment?
- BIOS/supervisor password / Absolute?
**STOP:** unresolved ownership/management lock unless legitimate release is documented.

## 4. Viability
- exact model / CPU / RAM / storage?
- supported OS/security life?
- obvious structural or liquid damage?
- replacement battery/charger available?
- likely resale > parts/scrap + labour + risk?

## 5. Route
Choose one **before acceptance**:
- REFURBISH
- PARTS
- DONATE/REUSE PARTNER
- DOWNSTREAM RECYCLE
- REJECT / OWNER RETAINS

If no credible route exists, **do not accept**.

## 6. Data
All accepted data-bearing devices:
**UNWIPED — RESTRICTED**
until sanitisation + verification are recorded.

## 7. Storage
Is there a labelled safe position available now?
If not, reject/defer intake rather than create an uncontrolled pile.
