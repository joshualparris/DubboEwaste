# 1. Practitioner-claim evidence register

| Claim | Evidence status | Research finding | Policy implication |
|---|---|---|---|
| Narrow ITAD can be simpler than broad e-waste | **Supported** | Australian reuse/ITAD firms separate valuable IT recovery from general end-of-life recycling | Start laptops/desktops, not all electronics |
| “Get in, refurb, get out” | **Supported principle** | mature operators use defined collect-assess-sanitise-route flows; value decays and WIP consumes capacity | track ageing and closure |
| Never pay for equipment | **Too absolute** | Renew IT and CompNow/SustainIT use buyback | early no-pay default, later buyback when valuation mature |
| Computer shops can be sources | **Plausible / test locally** | complementary business model is logical but local yield unknown | run one controlled pilot |
| Op shops generate lots of mixed electronics | **Plausible / local evidence needed** | policies and streams vary | accept only agreed IT categories |
| Public schools are a good direct source | **Constrained in NSW** | NSW public schools use departmental eWaste contract | pursue approved/subcontract/private-school routes |
| Blancco makes a stronger commercial story | **Supported as market positioning** | commercial reports/certifications/integrations are substantial | compare customer assurance vs licence cost |
| nwipe can be a useful open alternative | **Supported technically** | active open-source project with modern secure-erase support | pilot only with validation/evidence design |
| DBAN is similar enough | **Outdated as universal policy** | modern SSD/NVMe/mobile/SED workflows require media-aware sanitisation | no blanket DBAN standard |
| Soldering is not required for ordinary office refurb | **Supported** | many business laptops are highly modular; manufacturer repair docs available | modular skills first |
| $100k lab required for soldering | **Not supported** | basic solder/rework can start far below this; advanced BGA labs are separate | no specialist lab before business case |
| Gaming hardware needs more repair | **Plausible but weak evidence** | mechanisms exist but comparative data lacking | track local fault/labour data |
| Side volumes become large quickly | **Strong operational logic** | queue imbalance compounds; bulky accessories/downstream batches amplify space | hard WIP/stock caps |
| Basic labels can beat full integration early | **Supported by scale economics** | mature ERP is expensive/complex; small workflow gains should be measured | QR + AssetFlow first |
| Some double handling is acceptable | **Supported conditionally** | mature processing naturally has staged roles | multiple stages okay if identity/events remain clear |
| Purpose-built ERP can cost hundreds/month | **Supported** | Recycly and RazorERP public pricing show substantial cost | AssetFlow appropriate while small |
| Intake buckets should follow outflow/value | **Strongly supported** | ITAD firms assess then refurbish/resell/reuse/recycle | route by downstream outcome |
| Scrap pricing depends on knowledge/relationships | **Supported in principle** | commodity grades, settlement and logistics vary; exact anecdotal spread not generalisable | maintain dated price book |
| Trusted downstream partners are valuable | **Supported** | certifications/partner networks central to mature operators | vendor due diligence + reconciliation |
| Regional operators can use metro capability | **Supported strategic model** | no need to duplicate every specialised process locally | local vs partner matrix |
| Franchising is unnecessary at pilot stage | **Reasonable inference** | referral/subcontract/revenue share are simpler | pilot partnership before structure |
| Vintage hardware may be worth preserving | **Supported as exception** | collector markets exist; exact value is item-specific | short VINTAGE-REVIEW hold |
| Chargers become clutter quickly | **Supported operationally** | many standards/connectors/wattages; matching is a classification problem | dedicated accessory inventory |

# 2. Strongest corrections to the original advice

## Correction A — buyback

Use:
> **Do not pay before you can value.**

Not:
> Never pay.

## Correction B — sanitisation

Use:
> Approved media-aware sanitisation method + validation + evidence + release authorisation.

Not:
> Run a familiar wipe program.

## Correction C — schools

Use:
> Discover the organisation’s mandated disposal channel first.

Not:
> Schools are automatically available suppliers.

## Correction D — “recycling exemption”

Use:
> Ask NSW Fair Trading to confirm the exact legal character of the proposed model.

Not:
> Calling it recycling guarantees exemption from second-hand-dealer law.

## Correction E — automation

Use:
> automate repeated measured pain.

Not:
> integration is inherently better.

# 5. Research confidence scale

Use in future documents:

- **HIGH:** current primary source / regulator / direct standard requirement.
- **MEDIUM-HIGH:** multiple reputable operator/industry sources agree.
- **MEDIUM:** plausible and supported, but context-specific.
- **LOW-MEDIUM:** practitioner experience with limited independent evidence.
- **LOW:** anecdote/lead requiring validation.

Do not turn LOW/MEDIUM hypotheses into automatic workflow rules.
