# Android and Chromebook Support Lookup

## Google Pixel — primary policy
Google's current policy:
- Pixel 8 and later: **7 years** of OS/security updates from first US Google Store availability.
- Pixel 6/6a/6 Pro, 7/7a/7 Pro and Pixel Fold: **5 years**.
- Pixel 5a and earlier: no longer receive Android/security updates.

Source: https://support.google.com/pixelphone/answer/4457705?hl=en-AU

**Intake:** record exact model + original availability date and calculate remaining support rather than relying only on model age.

## Samsung
Use Samsung's current security-update scope/list for the exact model. Do not infer all Galaxy devices have the flagship support period. Older S21-class devices are now at/after their promised window while later flagships have longer policies.

Canonical lookup: https://security.samsungmobile.com/

## Motorola / Oppo
Support promises vary materially by model and region. Until the exact model's official product/security page is found, mark support as **UNKNOWN** rather than guessing from brand.

## Chromebook
Google maintains the authoritative Auto Update policy/model table:
https://support.google.com/chrome/a/answer/6220366

Examples relevant to education fleets:
- Lenovo 100e Chromebook 2nd Gen: current Google table should be checked by exact hardware platform; some variants differ.
- Lenovo 100e 2nd Gen MTK: table shows a different AUE from other 100e variants.
- Never use only the marketing name when multiple board/platform variants exist.

## Intake rule
For Android/Chromebook devices:
1. exact model/board;
2. official support/AUE page;
3. support-end date;
4. months remaining;
5. retail/donation/parts decision.

**PROPOSED POLICY:** ordinary resale should have enough remaining security-support life to be useful to the buyer; no universal month cutoff is asserted here.
