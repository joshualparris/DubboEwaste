# Certus

Checked: 2026-10-02 · Evidence: EVD-BENCH-011 · Role: Erasure

## Publicly advertised features

Vendor advertises laptop, server, storage and phone erasure with verifiable auditable reports. Erasure Web Manager exposes account login including SSO. A separate Erasure Verification Tool is described by the vendor.

## Limits and unresolved details

Do not treat the public 2018 manual as a current feature guarantee. Confirm user/licence/report management and verification support in the current version.

## AssetFlow implications

Use this product as a benchmark in these domains: DATA,INT. Build operational records and release controls in AssetFlow; use documented adapters for external device processing. Do not label a browser workflow as equivalent to its erasure engine, certification or physical automation.
