# Minimum Physical Shed Setup Checklist

**Purpose:** the smallest practical physical setup needed to run the Dubbo Phase 0 ITAD / electronics reuse pilot without pretending the shed is a warehouse.

**Status:** operational setup checklist only. Completing this checklist does **not** by itself establish Council approval, lease/landlord permission, insurance cover, Fair Trading compliance, fire/electrical adequacy, downstream acceptance or permission for general public intake.

## 1. Premises basics

- [ ] **UN-20261024-015-0019** Shed/work area is **dry, watertight and secure**.
- [ ] **UN-20261024-015-0020** No active mould, water ingress or known damp surface is used for equipment storage.
- [ ] **UN-20261024-015-0021** Entry/exit is clear and usable.
- [ ] **UN-20261024-015-0022** Walkway stays clear.
- [ ] **UN-20261024-015-0023** No ordinary inventory is stored on the floor.
- [ ] **UN-20261024-015-0024** Work/storage area is separate enough from household use to keep children, pets, food and personal clutter out while operating.
- [ ] **UN-20261024-015-0025** The exact area intended for business use is measured and documented privately.
- [ ] **UN-20261024-015-0026** Any unusable/damp/no-storage area is marked as excluded.

**Hard stop:** do not store valuable resale stock or unwiped client/business devices in a shed that is not demonstrably dry, secure and suitable.

## 2. Minimum furniture and storage

### Workbench

- [ ] **UN-20261024-015-0036** One solid workbench is available.
- [ ] **UN-20261024-015-0037** Bench has adequate lighting.
- [ ] **UN-20261024-015-0038** Bench is kept as a **processing position, not storage**.
- [ ] **UN-20261024-015-0039** Only one active device per operator work position.
- [ ] **UN-20261024-015-0040** Bench can be reset between restricted/unwiped and clean/cleared work.

You do **not** need separate wipe, test and repair benches for Phase 0.

### A — Intake / unassessed

- [ ] **UN-20261024-015-0046** One clearly labelled intake tray/shelf exists near the handoff point.
- [ ] **UN-20261024-015-0047** Initial cap: **2 devices or one small labelled batch**, whichever is lower.
- [ ] **UN-20261024-015-0048** Every accepted device gets an asset/source ID immediately.
- [ ] **UN-20261024-015-0049** Intake shelf is not used for long-term storage.

### B — Unwiped / restricted

- [ ] **UN-20261024-015-0053** One lockable cabinet, lockable cupboard or genuinely restricted storage position exists.
- [ ] **UN-20261024-015-0054** It is clearly labelled **UNWIPED — RESTRICTED**.
- [ ] **UN-20261024-015-0055** It is not accessible to visitors.
- [ ] **UN-20261024-015-0056** Sale-ready stock is never stored in the same location.
- [ ] **UN-20261024-015-0057** Initial cap: **4 data-bearing devices**.
- [ ] **UN-20261024-015-0058** Full zone = no new data-bearing intake.

### D — Repair / WIP

- [ ] **UN-20261024-015-0062** One small repair/WIP shelf or rack exists beside the bench.
- [ ] **UN-20261024-015-0063** Initial cap: **3 active devices**.
- [ ] **UN-20261024-015-0064** Each device has a fault/goal, next action and review date.
- [ ] **UN-20261024-015-0065** No device is allowed to become indefinite “I’ll get to it later” stock.

### E/F — Cleared QA / sale-ready

- [ ] **UN-20261024-015-0069** One clean shelf exists for cleared/QA stock.
- [ ] **UN-20261024-015-0070** One clean shelf or clearly separated section exists for **READY FOR SALE / REUSE**.
- [ ] **UN-20261024-015-0071** Clean/released stock is physically separated from unwiped devices.
- [ ] **UN-20261024-015-0072** Initial QA cap: **2 devices**.
- [ ] **UN-20261024-015-0073** Initial sale-ready cap: **4 devices**.

### G — Parts / donor

- [ ] **UN-20261024-015-0077** A small fixed number of labelled, lidded tubs exists.
- [ ] **UN-20261024-015-0078** Suggested initial categories:
  - [ ] **UN-20261024-015-0079** RAM
  - [ ] **UN-20261024-015-0080** known-status SSD/HDD/media
  - [ ] **UN-20261024-015-0081** chargers/adapters
  - [ ] **UN-20261024-015-0082** laptop donor parts
  - [ ] **UN-20261024-015-0083** cables/known-good accessories
- [ ] **UN-20261024-015-0084** No loose unidentified storage media.
- [ ] **UN-20261024-015-0085** No unsafe/swollen batteries.
- [ ] **UN-20261024-015-0086** Bin full = sort/use/outbound before adding another bin.
- [ ] **UN-20261024-015-0087** No miscellaneous “might be useful one day” pile.

### H — Return / downstream / outbound

- [ ] **UN-20261024-015-0091** One labelled outbound crate/shelf exists near the exit where practical.
- [ ] **UN-20261024-015-0092** Every item in outbound has a named destination and next date.
- [ ] **UN-20261024-015-0093** Return, recycler/destruction and sold dispatch assets remain identifiable.
- [ ] **UN-20261024-015-0094** No indefinite “outbound someday” stock.

## 3. Physical flow

The physical shed should support this simple one-way flow:

```text
HANDOFF OUTSIDE
      ↓
A  INTAKE / UNASSESSED
      ↓
B  UNWIPED — RESTRICTED
      ↓
C  PROCESSING BENCH
   sanitise → verify → diagnose
      ↓
D  REPAIR / WIP
      ↓
E  CLEARED QA
      ↓
F  READY FOR SALE / REUSE

Side exits:
A/B/C/D → G PARTS / DONOR
A/B/C/D → H RETURN / DOWNSTREAM / OUTBOUND
```

- [ ] **UN-20261024-015-0123** Intake is close to the door.
- [ ] **UN-20261024-015-0124** Unwiped storage is outside the visitor path.
- [ ] **UN-20261024-015-0125** Bench acts as the controlled crossing point between dirty/restricted and clean/released states.
- [ ] **UN-20261024-015-0126** Sale-ready stock is as far from the unwiped/intake lane as practical.
- [ ] **UN-20261024-015-0127** Outbound is near the exit where practical.
- [ ] **UN-20261024-015-0128** Nothing blocks the exit.

## 4. Electrical and charging basics

- [ ] **UN-20261024-015-0134** Power boards, chargers and leads are visibly sound and suitable for use.
- [ ] **UN-20261024-015-0135** Appropriate RCD/electrical protection for the actual workspace is confirmed.
- [ ] **UN-20261024-015-0136** No damaged leads/plugs are used.
- [ ] **UN-20261024-015-0137** No unattended charging.
- [ ] **UN-20261024-015-0138** No overnight charging.
- [ ] **UN-20261024-015-0139** No charging beside the only exit.
- [ ] **UN-20261024-015-0140** Charging/testing happens on a suitable, stable work surface.
- [ ] **UN-20261024-015-0141** Opened mains PSUs, mains wiring and other licensed electrical work are outside Phase 0 unless handled by a competent/licensed person as required.

## 5. Battery boundary

Phase 0 is **not** a damaged-battery collection service.

- [ ] **UN-20261024-015-0149** Loose lithium batteries are not accepted as a normal Phase 0 stream.
- [ ] **UN-20261024-015-0150** Visibly swollen, leaking, crushed, punctured, wet, overheated, smoking or fire-affected battery devices are refused before normal intake.
- [ ] **UN-20261024-015-0151** There is a written response for battery danger discovered only after acceptance.
- [ ] **UN-20261024-015-0152** If discovered after acceptance:
  - [ ] **UN-20261024-015-0153** stop work;
  - [ ] **UN-20261024-015-0154** do not charge or test;
  - [ ] **UN-20261024-015-0155** keep people away from the hazard;
  - [ ] **UN-20261024-015-0156** follow current NSW/site-specific emergency/isolation guidance;
  - [ ] **UN-20261024-015-0157** arrange an appropriate receiver/advice pathway promptly.
- [ ] **UN-20261024-015-0158** A generic metal box or improvised “battery bin” is **not** treated as proof of safe storage.

Battery hazard is an **exception / stop-work path**, not ordinary inventory.

## 6. Network and data basics

- [ ] **UN-20261024-015-0166** Unknown devices do **not** join the normal home/business LAN during ordinary triage.
- [ ] **UN-20261024-015-0167** Offline tools or an isolated/segregated test network are available where needed.
- [ ] **UN-20261024-015-0168** Every possible data-bearing device goes to **UNWIPED — RESTRICTED** by default.
- [ ] **UN-20261024-015-0169** No data-bearing asset moves to clean/sale stock without a recorded media decision and verification.
- [ ] **UN-20261024-015-0170** Removed drives/media stay linked to the parent asset or their own media record.
- [ ] **UN-20261024-015-0171** No loose unidentified drives.

## 7. Visitor and handoff boundary

- [ ] **UN-20261024-015-0177** Customer/source handoff occurs outside the workshop or at the doorway.
- [ ] **UN-20261024-015-0178** Visitors do not enter unwiped, repair, parts or sale-ready zones.
- [ ] **UN-20261024-015-0179** No unattended drop-off.
- [ ] **UN-20261024-015-0180** No gate pile.
- [ ] **UN-20261024-015-0181** No public e-waste bin.
- [ ] **UN-20261024-015-0182** No outdoor stockpile.
- [ ] **UN-20261024-015-0183** One source/batch at a time where practical.
- [ ] **UN-20261024-015-0184** A device is refused/rescheduled if there is no safe physical location available.

## 9. Initial stock limit

The 20–30 device Phase 0 pilot is a **cumulative sample**, not simultaneous storage permission.

- [ ] **UN-20261024-015-0225** Start with a provisional overall cap of **12 serialized devices physically held at once**.
- [ ] **UN-20261024-015-0226** Review the cap after device 5.
- [ ] **UN-20261024-015-0227** Review again after device 10.
- [ ] **UN-20261024-015-0228** Do not raise the cap unless:
  - [ ] **UN-20261024-015-0229** every asset is easy to locate;
  - [ ] **UN-20261024-015-0230** no data-state confusion has occurred;
  - [ ] **UN-20261024-015-0231** no zone is chronically full;
  - [ ] **UN-20261024-015-0232** repair/WIP is moving;
  - [ ] **UN-20261024-015-0233** sale-ready stock is actually leaving;
  - [ ] **UN-20261024-015-0234** downstream routes work;
  - [ ] **UN-20261024-015-0235** the actual premises/insurance/capacity evidence permits it.

The 12-device figure is an **operating experiment cap**, not a fire, structural, insurance or regulatory limit.
