# Dubbo E-Waste glossary

| Term | Meaning in this repository |
|---|---|
| ABM/DEP | Apple Business Manager / Device Enrolment Programme; organisational management that can survive reset. |
| ACL | Australian Consumer Law. Applies to business sales and consumer guarantees. |
| AS/NZS 5377 | Australian/New Zealand standard for environmentally sound e-waste collection, storage, transport and treatment. |
| AUE | Auto Update Expiration for Chromebooks. The date Google stops automatic updates for a model. |
| B-cycle | Australian battery product-stewardship scheme. |
| Chain of custody | Record of who controlled an asset/material and when, from intake to final route. |
| eMMC | Embedded flash storage common in phones, tablets and low-cost computers. |
| Erase/sanitise | A controlled process that makes data infeasible to access for the intended threat model; the method must match the media. |
| FRP | Android Factory Reset Protection; an account lock that can make a reset device unusable to a new owner. |
| FMV | Fair market value; a pricing estimate supported by comparable sold results, condition and costs. |
| IMEI | International Mobile Equipment Identity; a mobile-device identifier used for provenance/blacklist checks. |
| ITAD | Information Technology Asset Disposition: secure collection, inventory, data handling, reuse/resale and final recycling of IT assets. |
| MDM | Mobile Device Management; organisational control over a device. |
| NTCRS | National Television and Computer Recycling Scheme. Covers designated TVs, computers, printers, parts and peripherals. |
| OOBE | Out-of-box experience; the setup flow where Windows management/Autopilot status may become visible. |
| PCB | Printed circuit board. Sorted boards may have parts or scrap value but need a known route. |
| PCBU | Person conducting a business or undertaking under Australian WHS law. |
| R2v3 | SERI's Responsible Recycling standard; do not claim certification without current scope evidence. |
| Reuse | Keeping an item or component functional for another user or purpose. |
| Route | The declared next disposition: reuse, repair, donor, parts, social reuse, recycling or reject. |
| NTCRS co-regulator | Approved organisation administering collection/recycling obligations for liable parties under NTCRS. |
| Triage | Fast evidence-based decision about safety, ownership, locks, value and route before accepting work. |
| Win11 eligible | Meets Microsoft's current Windows 11 hardware requirements; verify rather than infer from age. |
