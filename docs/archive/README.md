# Historical and provenance material

DubboEwaste intentionally retains older research so later corrections can be traced.

## Rule

**Archived/historical does not mean useless. It means it is not the first place to look for current truth.**

When a historical document conflicts with current material:

1. use [../CURRENT-STATE.md](../CURRENT-STATE.md);
2. use [../RESEARCH-INDEX.md](../RESEARCH-INDEX.md) to find the current topic authority;
3. preserve the older document as provenance unless there is a privacy, security or legal reason to remove it.

## Future archive move

A later cleanup can move historical material under a single `archive/` tree only after:

- inbound references have been enumerated;
- links have been rewritten;
- the repo-wide link audit passes;
- current canonical documents no longer depend on historical paths.

This avoids a tidy-looking repository with broken evidence trails.
