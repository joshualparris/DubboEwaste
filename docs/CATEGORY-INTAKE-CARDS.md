# Category-Specific Intake Cards

## Windows laptop / desktop
**Accept preference:** Windows 11-supported CPU/platform, TPM/Secure Boot-capable, 8 GB+ RAM as **PROPOSED POLICY**, SSD upgrade feasible, no unresolved Autopilot/BIOS/Absolute lock.  
**Check:** model, CPU, RAM, SSD/HDD, charger, hinges/screen, battery, ports, BIOS password, Autopilot/OOBE, Windows activation.  
**Route older systems:** Linux/special use only when demand is known; otherwise parts/scrap.

## Mac
Check exact model/year, current macOS support, Activation Lock, Find My, ABM/MDM, battery/service status, keyboard/display, charger.  
**Reject resale:** unresolved Activation Lock/MDM.

## iPhone / iPad
Check IMEI/serial, Activation Lock/Find My, ABM/MDM, carrier/IMEI status, battery, Face/Touch ID, cameras, display, charge port, current iOS/iPadOS support.  
Owner removes account/lock before transfer.

## Android phone / tablet
Check IMEI, FRP/account protection, Knox Guard/enterprise enrolment where relevant, carrier block, current security-support horizon, battery, display, cameras, charge port, 000/network compatibility.  
Avoid factory-resetting before legitimate account removal is confirmed.

## Chromebook
Check exact model, Auto Update Expiration date, enterprise enrolment, battery, keyboard/trackpad, USB-C power, display.  
**Reject resale:** unresolved enterprise enrolment.

## Monitor
Check panel cracks/pressure spots/dead pixels/backlight, ports, stand/VESA, power supply, burn-in, resolution.  
Avoid low-value bulky units without local sale or downstream route.

## TV
Phase 0 preference: modern flat-screen/smart TV with known working status and local-sale/downstream route.  
Check panel damage, backlight, HDMI, remote, stand, smart-platform support.  
Do not accept CRTs until downstream acceptance is confirmed.

## Networking gear
Check exact model, reset/admin ownership, firmware/support status, PSU, PoE, licensing/cloud lock.  
Enterprise gear can be valuable but may be useless with subscription/account binding.

## Printers
Generally low priority. Accept only with a known resale/donation route; toner/ink leakage and consumable cost can erase margin.
