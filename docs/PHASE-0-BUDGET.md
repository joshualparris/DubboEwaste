# Phase 0 Budget

## Principle
Do not buy enterprise tooling before the 30-device pilot proves supply and economics.

## Required / near-required
| Item | Budget basis |
|---|---:|
| software wipe/diagnostic kit | $0 initially using vetted open-source/free tools |
| basic ESD + hand tools + known-good chargers/adapters | use existing where safe; fill gaps only |
| labels/storage tubs/lockable unwiped storage | small setup allowance |
| packaging | variable per sold device |
| replacement SSD/RAM/batteries | only per profitable repair |
| insurance | **quote required** |
| second-hand dealer licence | $692/1yr only if Fair Trading confirms required |
| planning/DA | unknown until Council response |
| downstream | often low/zero for eligible streams; commercial destruction may cost |

## Working-capital rule
Set a maximum cash tied in unsold stock. Suggested pilot policy:
- no more than 10 active unsold refurb units at once;
- no speculative battery/part order unless expected margin remains positive after labour;
- auction purchases require max-bid calculation.

## Break-even
```
fixed_setup_cost / median_net_profit_per_sold_device = devices_to_break_even
```
Do not calculate a false break-even until insurer/planning/licensing costs and pilot net profit are real.
