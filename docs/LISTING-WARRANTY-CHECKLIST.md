# Listing, warranty and return checklist

Complete before publishing a refurbished or used device listing. This checklist supports the existing sale/recall and repair-notice templates; it is not legal advice.

- [ ] **UN-20261024-019-0005** Asset ID, serial/IMEI and provenance record linked.
- [ ] **UN-20261024-019-0006** Ownership/authority and management-lock checks recorded.
- [ ] **UN-20261024-019-0007** Sanitisation method, result and certificate ID recorded where applicable.
- [ ] **UN-20261024-019-0008** Model, CPU/RAM/storage, operating system and charger/accessory contents verified.
- [ ] **UN-20261024-019-0009** Cosmetic grade and every material defect photographed and described.
- [ ] **UN-20261024-019-0010** Battery health/condition disclosed; no unsupported battery-life promise.
- [ ] **UN-20261024-019-0011** Functional test date and test scope recorded.
- [ ] **UN-20261024-019-0012** Price, postage, packaging and expected dispatch time checked.
- [ ] **UN-20261024-019-0013** Warranty/consumer-guarantee wording reviewed; no “no refunds” or misleading “as-is” language.
- [ ] **UN-20261024-019-0014** Repair limitations, data-loss risk and customer backup responsibility disclosed where relevant.
- [ ] **UN-20261024-019-0015** Buyer contact and sale/recall record created.
- [ ] **UN-20261024-019-0016** Return/remedy process and stock reserve understood before publication.
