Smart Intake now uses Cloudflare Workers AI / Mistral through a secret-protected Worker after Vercel AI Gateway returned 403. Server-only Vercel variables SMART_INTAKE_WORKER_URL and SMART_INTAKE_WORKER_SECRET connect to it. The worker requires the AI and INTAKE_SECRET bindings. Build QA submits a synthetic non-customer Dell label to the actual provider using the same server adapter and checks parsed inventory, serial and model. The app still requires user consent and ownership confirmation. Photos are not stored by AssetFlow; Cloudflare processing applies. No production database writes occur during this smoke test.
