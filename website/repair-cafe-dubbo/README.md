## How to update

1. Edit the canonical `website/repair-cafe-dubbo/index.html` on `main`.
2. Test all in-page links, mobile breakpoints, keyboard navigation and copy.
3. Publish the **same content** to `gh-pages:repair-cafe-dubbo/index.html`.
4. Check the real GitHub Pages URL and confirm the expression-of-interest form works. GitHub Pages deployments can lag behind git commits.
5. Do not claim any venue/date, grant award, legal registration, partnership, insurance or payment processing without documented confirmation.

The website itself stores no personal information, has no cookies, tracking or JavaScript and sends sponsor/venue enquiries to the organiser's existing public email. The optional existing expression-of-interest form runs on a separate application and therefore has separate privacy and availability requirements.
