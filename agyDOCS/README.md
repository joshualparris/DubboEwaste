# agyDOCS — legacy research, not canonical

These files were generated during an earlier AI research pass. They contain useful leads, but the original work mixed verified facts, generic ITAD practice and unsupported specifics.

## Rules for using this folder
1. Prefer `docs/CURRENT-STATE.md`, `docs/RESEARCH-INDEX.md` and `claudeDOCS/` for current operational decisions.
2. Treat anything not backed by a primary source or explicitly marked policy as unverified.
3. Do not attribute generic ITAD workflows to Fliptech, Sircel, WorkVentures, PonyUp or another company unless a source actually documents that company's practice.
4. Do not rely on this folder for lithium shipping rules; use `docs/AU-SHIPPING-MATRIX.md` and current carrier guidance.
5. Battery-health, RAM/age cutoffs and A/B/C-style grades are internal policy choices unless a marketplace/operator specifically publishes its own threshold.
6. `00-CORRECTIONS-AND-CAVEATS.md` records the major corrections, but the canonical documents outside this folder supersede it where newer.
