# Listing, warranty and return checklist

Complete before publishing a refurbished or used device listing. This checklist supports the existing sale/recall and repair-notice templates; it is not legal advice.

- [ ] Asset ID, serial/IMEI and provenance record linked.
- [ ] Ownership/authority and management-lock checks recorded.
- [ ] Sanitisation method, result and certificate ID recorded where applicable.
- [ ] Model, CPU/RAM/storage, operating system and charger/accessory contents verified.
- [ ] Cosmetic grade and every material defect photographed and described.
- [ ] Battery health/condition disclosed; no unsupported battery-life promise.
- [ ] Functional test date and test scope recorded.
- [ ] Price, postage, packaging and expected dispatch time checked.
- [ ] Warranty/consumer-guarantee wording reviewed; no “no refunds” or misleading “as-is” language.
- [ ] Repair limitations, data-loss risk and customer backup responsibility disclosed where relevant.
- [ ] Buyer contact and sale/recall record created.
- [ ] Return/remedy process and stock reserve understood before publication.
