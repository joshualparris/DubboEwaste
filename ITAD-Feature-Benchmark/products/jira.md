# Jira Service Management Assets

Checked: 2026-10-02 · Evidence: EVD-BENCH-022 · Role: ITSM / ITAM

## Publicly advertised features

Asset/configuration repository with ownership, lifecycle and operational history, relationships, reporting, scheduled imports, Data Manager bulk operations and integrations. Assets can link to requests, incidents and changes.

## Limits and unresolved details

Former Jira Service Desk name is outdated. Assets entitlement and limits depend on current plan. Retired is a configured lifecycle value, not a guaranteed automatic ITAD integration.

## AssetFlow implications

Use this product as a benchmark in these domains: LIFE,INT. Build operational records and release controls in AssetFlow; use documented adapters for external device processing. Do not label a browser workflow as equivalent to its erasure engine, certification or physical automation.

## Demo questions

- Which current edition, versions and device models support the advertised workflow?
- Can we obtain a sample report, API schema and failed-operation example?
- Which capabilities require add-ons, hardware, paid lookups or managed services?
- How are identity conflicts, retries, operator overrides and evidence integrity handled?
