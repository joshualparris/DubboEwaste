# DubboEwaste Learning Curriculum

## Before pilot
1. **Lithium safety:** complete the free UNSW/available battery-safety material identified in repo research; read FRNSW guidance.
2. **PC hardware:** Professor Messer A+ Core 1 hardware/troubleshooting sections or equivalent free material.
3. **Data sanitisation:** NIST SP 800-88 Rev.2 concepts; practise ShredOS/nwipe for HDD and native NVMe/ATA sanitize methods.
4. **Locks:** Apple Activation Lock, Android FRP, Windows Autopilot, Chromebook enterprise enrolment.
5. **ACL basics:** acceptable quality, disclosed defects, major/minor failure, no blanket “no refunds”.
6. **Bench tools:** Ventoy, smartctl, nvme-cli, MemTest86, stress-ng.

## During first 30 devices
- battery reports and charge-cycle interpretation;
- model service manuals (Dell/HP/Lenovo);
- Windows firmware/OEM activation;
- common business-laptop failure patterns;
- safe cleaning and thermal service;
- eBay sold-data capture and listing quality;
- return/failure root-cause review.

## After pilot proves demand
- test-and-tag training if regulator guidance/business model makes it useful;
- formal IT support qualification if desired (research favours ICT30120 over UEE30920 for practicality);
- soldering/board-level repair only after basic economics prove it is worth the skill/time;
- ITAD certifications only if target clients require them.

## Do not prioritise now
- discontinued iFixit MasterTech;
- expensive enterprise sanitisation software before volume/client requirements justify it;
- long trade qualification solely to run a 30-device pilot.
