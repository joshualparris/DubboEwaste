# Cost picture (estimates unless marked VERIFIED)

## Shed-based, cheapest version
| Item | Cost |
|---|---|
| Wipe tools (nwipe etc.) and certificate template | $0-$300 |
| Metal battery bin, extinguisher, smoke alarm | $100-$500 |
| Shelving/bench (second-hand) | $0-$300 |
| Public liability insurance | ~$800-$1,500/yr, get 2-3 quotes |
| **Second-hand dealer licence, if required** | **$692 (1 yr) VERIFIED; $1,574 (3 yr); $2,456 (5 yr)** |
| DA / council consent, if required | **Unknown** |
| Listing/marketplace fees | eBay fee rules changed in 2026; business sellers roughly 13% GST-incl. (secondary source) |
| Leftover disposal | $0 if NTCRS/Whylandra accepts; else per item |

Don't budget the $692 yet: check whether you need it (recycling-program exemption, or operating under an already-licensed entity).

## Larger options (for comparison)
- Lean rented-space start: ~$5k-$15k
- Bigger hub (baler, forklift, scales, staff): $30k-$100k+

## Forgotten ongoing costs
- Disposal of zero-value items
- Your own labour
- Insurance renewals; licence renewals ($500/yr after the first year)
- GST registration is compulsory at A$75,000 turnover (my understanding; confirm with the ATO)

## Profit test per item
Resale price minus: platform fees, postage/packaging, parts, wipe/test time, 14-day-hold storage effect (if licensed), and any disposal cost.
