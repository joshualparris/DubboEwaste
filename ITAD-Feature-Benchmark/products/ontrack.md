# Ontrack / legacy Kroll Ontrack

Checked: 2026-10-02 · Evidence: EVD-BENCH-013 · Role: Erasure

## Publicly advertised features

Current Ontrack support lists Blancco erasure software, Ontrack HostedErase and eraser degausser support. Software pages distinguish whole-drive erasure from selective file/folder erasure; Hosted Erase material describes Blancco-backed delivery.

## Limits and unresolved details

Legacy Kroll branding is not proof of a separate current erasure engine. Confirm the exact underlying product before designing an adapter; selective file erasure is not whole-device sanitisation.

## AssetFlow implications

Use this product as a benchmark in these domains: DATA,INT. Build operational records and release controls in AssetFlow; use documented adapters for external device processing. Do not label a browser workflow as equivalent to its erasure engine, certification or physical automation.
