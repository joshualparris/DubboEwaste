# Decision Log

## D01 — Reuse before recycling
**Decision:** test for safe/economic reuse before material recycling.  
**Why:** preserves more value and aligns with documented reuse-first models.  
**Limit:** unsafe/locked/uneconomic devices route downstream.

## D02 — Windows 11 as ordinary Windows resale floor
**Decision:** normal Windows retail targets officially supported Windows 11 hardware.  
**Why:** Windows 10 standard support ended 14 Oct 2025.  
**Exception:** clearly disclosed Linux/vintage/special-use sale with real demand.

## D03 — 8 GB RAM is policy, not law
**Decision:** 8 GB minimum for ordinary Windows office resale as a **PROPOSED POLICY**.  
**Why:** practical usability; Microsoft's formal minimum is not the same thing.

## D04 — No public battery drop-off
**Decision:** Phase 0 does not collect loose/damaged batteries.  
**Why:** fire risk and downstream complexity.

## D05 — No unattended public e-waste bin
**Decision:** appointment/pre-approved intake only.  
**Why:** planning, dumping, safety, stolen-goods and storage risk.

## D06 — Data devices start restricted
**Decision:** data-bearing assets begin as **UNWIPED — RESTRICTED**.  
**Why:** privacy and chain-of-custody.

## D07 — Known-source first
**Decision:** learn using known/authorised sources before broad public intake.  
**Why:** provenance, model consistency and lower risk.

## D08 — Do not claim certified destruction
**Decision:** say “documented secure data erasure” unless actual certification/provider evidence supports stronger wording.

## D09 — Platform/carrier rules are service-specific
**Decision:** no generic “all lithium goes road only” or universal marketplace fee rule.

## D10 — Pilot before scaling
**Decision:** first 30 accepted devices must generate evidence before warehouse/public-drop/staff/enterprise-tool investment.
