## Demand

## Repair First participation
Ask:
- Would an instant customer repair discount create useful additional work?
- Would you prefer the program to pay you directly or another settlement method?
- What admin burden is acceptable per job?
- Would you offer a low-cost Repair Check / diagnostic slot?
- Would you accept referrals from a Repair Café?
- Would you share de-identified outcome data?
- Would you use safe donor/refurbished parts where suitable and disclosed?
- What would make you refuse to participate?

## Close

# 6. 30-day follow-up

Ask:
1. Is the item still working?
2. Have you used it since the repair?
3. Did you buy a replacement anyway?
4. Are you satisfied with the repair?
5. Would you use the same repairer again?
6. Would you get a Repair Check before replacing another broken item?
7. Did you repair another item since?
8. Any repeat fault?
9. Anything that made the process harder than buying new?

Suggested 1–5 measures:
- confidence in repair
- trust in repairer
- convenience
- value for money
- likelihood to repair first next time

---

# 7. Six-month follow-up

Where consent allows:
- item still in use?
- additional repair needed?
- replacement eventually purchased?
- useful-life extension observed:
- has household used repair again?
- program still influenced decision?

---

# 12. Minimum evidence before a cash bonus

Do not launch a repair rebate until there is evidence for:
- at least several participating repairers across the first categories;
- spare capacity;
- typical diagnosis fees;
- typical repair/replacement ratios;
- an admin/payment mechanism;
- consumer-rights/warranty exclusion rules;
- safe category boundaries;
- baseline repair conversion;
- outcome data method.

A Repair Check + directory + Repair Café can begin earlier and generate this evidence.
