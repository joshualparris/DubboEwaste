## F. Synthetic drill and daily check

Use healthy personally owned devices, fake identities/data and pictures for hazards. Never practise with a live damaged battery or private donor files.

|---|---|---|
| Normal accept | Authority, ID, permitted work and reserved location | |
| Uncertain authority | Refuse/defer before custody | |
| Account/admin lock | No bypass; defer or lawful restricted hold within scope | |
| Unknown data/removed drive | Linked device/media; restricted; no release | |
| Full restricted shelf | Reschedule/refuse even with empty bench | |
| Battery emergency tabletop | Evacuate/stay out/000; no carrying or repair attempt | |
| Receiver rejects load | Pause lane; lawful custody and revised route | |
| Record recovery | Synthetic backup restores accurately | |

**Open:** no water/hazard/blocked exit; stock matches records; access control works; holds/overdue items reviewed; route current; today's batch fits capacity/supervision.

**Close:** no unattended charging; equipment safely off; unwiped media/records secured; stock located; hazards/escalations recorded; next action and owner assigned.
