# Dubbo E-Waste Field School (GitHub Pages build)

This is the deploy branch for the study site at https://joshualparris.github.io/DubboEwaste/.

`index.html` is generated from the docs on `main`. The generator's source is in `src/`.

Rebuild: `python3 src/build.py <path-to-DubboEwaste-main-checkout> index.html --standalone`
