# What Would Prove DubboEwaste Works?

Review after first 30 accepted devices.

| Metric | Green | Amber | Red |
|---|---:|---:|---:|
| net profit after labour | positive and repeatable | near break-even | negative |
| profit per labour hour | meets chosen minimum | below goal but improving | persistently poor |
| whole-device reuse rate | ≥50% of pre-screened intake | 30–49% | <30% |
| return rate | <5% | 5–10% | >10% |
| INAD/fault complaints | <2% | 2–4% | >4% |
| median days in stock | <30 | 30–60 | >60 |
| repeat suppliers | ≥2 | 1 | 0 |
| storage control | within capacity | occasional overflow | chronic pile |
| downstream cost | small vs recovered value | material | destroys margin |
| sanitisation success/records | 100% | isolated rework | uncontrolled failure |
| safety incidents | 0 | near miss reviewed | incident/unsafe pattern |
| provenance/lock failures | rare/pre-screened | recurring | common |

## Decision
- **GO:** all legal/insurance gates closed + economics mostly green.
- **NARROW:** profitable only in certain categories/sources → cut the rest.
- **PAUSE:** red safety/compliance or persistently negative economics.
