Offline Library

No library files were found yet. The library reads .zim files, which hold whole websites such as Wikipedia, Project Gutenberg books or Khan Academy lessons.

  1. On any computer with internet, download a .zim file from library.kiwix.org. Smaller "mini" or "nopic" editions suit older computers.
  2. Copy it to a USB stick, or into the Library folder in your home folder.
  3. Open Offline Library again. It will appear in your browser, with no internet needed.
