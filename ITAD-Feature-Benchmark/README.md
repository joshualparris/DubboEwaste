# ITAD product benchmark

Researched 2026-10-02. Scope: public vendor documentation and published product material for all 25 named products/platforms. No paid accounts, private screens, vendor demos or hardware benchmarks were accessed.

**Goal:** AssetFlow should ultimately cover the deduplicated union of these capabilities, then add useful Dubbo/Australian features. This is a product ambition, not a claim of existing parity, exhaustive discovery or superior performance.

Read [product profiles](products/), [combined catalogue](feature-catalogue.md), [delivery roadmap](roadmap.md), [integration design](integration-design.md), [coverage matrix](coverage-matrix.csv) and [research gaps](research-gaps.md). Machine-readable requirements: [feature-catalogue.csv](feature-catalogue.csv).

## Evidence and status

Profiles mean **vendor-advertised** unless specifically described as historical. A public claim is not hands-on verification. Requirement rows are **proposed**, not shipped. Domain links in the matrix mean research scope only, not proof that a vendor implements every requirement in that domain. Evidence records EVD-BENCH-* in ../data/evidence.yaml preserve this distinction.

Existing implementation claims in [OpenSourceSoftware/feature-backlog.md](../OpenSourceSoftware/feature-backlog.md) were not re-audited here. Maintain its statuses separately; map each new requirement to an implementation and test before assigning completion.
